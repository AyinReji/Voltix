Build a complete, premium, realistic **frontend-only e-commerce website** for a fictional Indian electronics and gadgets brand called **VOLTIX**.

The website should feel like a real, modern e-commerce store similar in structure and usability to a professional Shopify store, while having its own visual identity.

## CORE OBJECTIVE

Create an online store selling:

* Smartphones & accessories
* Wireless earbuds
* Headphones
* Smartwatches
* Power banks
* Chargers
* Cables
* Bluetooth speakers
* Laptop accessories
* Smart gadgets

This is a **frontend-only portfolio/demo project**.

Do NOT build:

* Backend
* Database
* Authentication
* Admin dashboard
* Real payment processing
* Real order processing

Use realistic mock product data and local state/localStorage.

# VISUAL DIRECTION

Create a clean, modern electronics-store aesthetic.

Use:

* White / very light gray background
* Black / charcoal typography
* Deep blue or electric violet as the accent
* Clean product photography
* Sharp product cards
* Strong typography
* Subtle shadows
* Thin borders
* Minimal gradients
* Small amounts of rounded corners
* Smooth micro-interactions

The website should feel like a **premium modern electronics retailer**, not a cheap marketplace.

Avoid:

* Excessive neon
* Cyberpunk styling
* Excessive glassmorphism
* Excessive gradients
* Overly dark interfaces
* Giant unnecessary text
* Excessive animations
* Cluttered product cards

# FINAL QUALITY STANDARD

The final result should feel like a **real modern Indian electronics e-commerce store**, not a landing page or AI-generated template.

It should have the shopping psychology of a real Shopify store:

**Discover → Compare → Trust → Add to Cart → Checkout**

The first 5 seconds should communicate:

**What does VOLTIX sell?**

**What should I buy?**

**Why should I trust this store?**

**Where do I start shopping?**

Prioritize conversion, product discovery and visual polish.

Do not add:

* Blog
* SEO content
* Admin dashboard
* Backend
* Complex unnecessary features

Make it polished enough to present directly as a **Kaeon Studios e-commerce portfolio project**.
